# AL Task Delivery — Pilot Prompts

## Pilot A — Historical reconstruction
Review this completed Asana task as if you were responsible for delivering it. Read all relevant task discussion and linked HubSpot/Notion context. Using the AL Task Delivery framework, reconstruct what was being solved, what should have happened, what actually happened, the breakpoint, solution, tests, and final verified result. Do not make any writes.

## Pilot B — Live bounded task
Complete this task as far as your current authority and tools allow. Do not stop at a summary. Read the complete relevant context, perform authorized work, verify the result, and update the existing Asana task only after I approve the proposed write. If implementation requires Cursor/Codex, create a self-contained implementation handoff and leave implementation open until verified.

## Pilot C — Verification challenge
Re-check this task's claimed resolution from the live systems. Treat the existing task summary as a claim, not proof. Return PASS / FAIL / UNKNOWN / BLOCKED against the actual definition of done and cite the live evidence that supports the result.
