# Apartment Life Task Framework

Use this flexibly; omit empty/non-applicable sections rather than filling them with fluff.

## Links
- HubSpot ticket / record / workflow
- Asana task
- Notion / documentation / meeting
- implementation or test links

## Start here

## What are we solving for?
State the concrete business/system result.

## Additional Context
Only context that materially changes the task.

## What's trying to be done & why?
Who is trying to do what and why.

## Data / Systems
- Systems
- Object
- Field
- Internal name
- Workflow / automation
- Relevant IDs

## What actually happened? & What was the outcome?
Observed evidence only.

## What should have happened?
Use TRAC:
- **Trigger**
- **Results / Outcomes**
- **Activities / main milestones**
- **Changes / variations**

## Questions / observations / comparison
Compare expected vs actual and identify the supported breakpoint.

## Solution Steps
Actionable sequence.

## Code
Original and new code when relevant. Preserve the technical source of truth in the appropriate repository/workflow history.

## Testing
Tests must map to the business rule and meaningful edge cases.

## Chat link
If useful for continuity.

## Resolution
What is now true, with evidence.

## Task comms
Concise stakeholder update.

## Documentation
Update reusable documentation when the change affects an ongoing process.

## Learnings
Record reusable system/process insight, not generic commentary.
